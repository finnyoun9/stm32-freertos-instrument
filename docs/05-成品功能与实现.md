## 6. 关键设计问题（要能自己讲出来）

1. 采样率的上限由哪个环节决定？想再快一倍要改什么？
2. 显示刷新和采样之间怎么保证不丢数据？
3. 示波器和万用表共用哪些资源？会不会互相干扰（同一 ADC / 同一 DMA / 同一 LCD）？
4. 用 FreeRTOS 相比裸机大循环，在这个项目里具体解决了什么问题？
