# 01 · 开发板

> 本页信息来自 **bench 上的完整工程** `firmware/my/demo/demo.ioc` + `Core/Src/main.c`，以及 `hardware/schematic/FreeRTOS开发板电路图.pdf`。

## 板子来源

- [x] 课程配套开发板（铁头山羊 FreeRTOS 课程板），跟课制作/焊接
- [ ] 自己画板

| 项 | 内容 |
| --- | --- |
| 板子名称 | 铁头山羊 FreeRTOS 课程板 |
| 主控 MCU | **STM32F103RCT6**（LQFP64，256KB Flash / 48KB SRAM） |
| 系列/型号串 | STM32F103R(C-D-E)Tx |
| 主频 | **72 MHz**（HSE 8MHz → PLL ×9） |
| 总线时钟 | AHB 72MHz / APB1 36MHz / APB2 72MHz |
| ADC 时钟 | PCLK2 ÷ 6 = **12 MHz** |
| HAL 时基 | TIM6（SysTick 让给 FreeRTOS） |
| 调试口 | SWD：PA13 (SWDIO) / PA14 (SWCLK) |
| 原理图 | `hardware/schematic/FreeRTOS开发板电路图.pdf` |

## 板上资源与引脚（已从代码核对）

| 资源 | 接口 / 引脚 | 说明 |
| --- | --- | --- |
| LCD | SPI1：PB3 (SCK) / PB5 (MOSI)；RS=PC12，NSS=PD2，RST=PB4，BL=PB6 | 分辨率 **320×240**（`lcd.h` 坐标系 0~319 / 0~239），SPI 18 Mbit/s，数据走 DMA |
| 按键 ×6 | KEY1=PC9，KEY2=PA8，KEY3=PC15，KEY4=PC0，KEY_UP=PC13，KEY_DOWN=PC14 | 全部上拉输入，低电平按下 |
| LED | LED1 = PC3 | 心跳/状态 |
| 蜂鸣器 | PC8 | 按键音效（当前输出代码被注释） |
| 示波器输入 | PA1 = ADC1_IN1（常规序列） | 12 位，外部触发 TIM3_TRGO |
| 触发输入 | PA3 = EXTI3（上升沿） | 边沿触发信号 |
| 触发电压 | ADC1 注入序列 rank4 = CH0 (PA0) | 由电位器给定，软件读回 |
| 信号发生器输出 | PA4 = DAC_CH1 + TIM5_TRGO | 12 位，DMA 送波形表 |
| 万用表挡位检测 | PB12=DMM50V，PB13=DMM10V，PB14=DMM2V，PB15=DMM10kΩ，PC6=DMM100kΩ，PC7=DMM1MΩ | 下拉输入，高电平表示当前挡位 |
| 万用表/电源模拟量 | ADC1 注入序列：rank1=CH9(PB1)，rank3=CH8(PB0) | rank1 万用表运放输出，rank3 稳压电源输出（×13 换算） |
| 基准 | ADC1 注入 rank2 = VREFINT（239.5 周期采样） | 反推 VDDA，见 `App/dmm.c` |
| 串口 | USART1：PA9 (TX) / PA10 (RX) | 115200 8N1 |
