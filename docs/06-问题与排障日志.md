# 06 · 问题与排障日志

> 规则：**一条一个坑，按时间倒序追加**（最新的在最上面）。
> 每条必须写全四段：现象 → 假设 → 验证 → 结论。没有验证过程的条目，说明还没定位完。

---

## 模板（复制这一段用）

```markdown
## YYYY-MM-DD · 一句话标题

- **现象**：看到什么（报错原文 / 波形 / 数值）
- **影响**：挡住了什么功能
- **假设**：列出 1~3 个可能原因，按可能性排序
- **验证**：每个假设怎么排除的（改了什么、测了什么、看到什么）
- **结论**：根因是什么
- **修复**：改了哪个文件哪一行
- **遗留**：有没有同类风险点
- **证据**：`docs/evidence/xxx.png`
```

## 常见方向速查（先怀疑这些）

| 类别 | 先查 |
| --- | --- |
| 一进调度器就 HardFault | 中断向量映射、优先级分组、`configPRIO_BITS`、栈大小 |
| 任务不切换 | 优先级配置、`vTaskDelay` 有没有、是不是死循环不让出 |
| 串口乱码 | 波特率、时钟配置（HSE 是否起振）、`printf` 重定向 |
| 中断里调用 API 后跑飞 | 用了非 `FromISR` 版本 / 中断优先级过高 |
| 内存分配失败 | `configTOTAL_HEAP_SIZE`、是否泄漏、碎片 |
| LCD 花屏/无显示 | 初始化时序、背光、数据宽度、FSMC 时序参数 |
| 采样波形失真 | 采样率不足、参考电压、输入阻抗、DMA 缓冲覆盖 |
