## 4. 堆内存管理

**机制**：FreeRTOS 自带 5 种 heap 方案，在分配策略、能否释放、碎片风险上不同。

- **我的理解**：待填
- **项目落点**：待填（最终选了哪个 heap_n、为什么）
- **证据**：待填（`xPortGetFreeHeapSize()` 前后对比、map 文件占用）

| 方案 | 能否 free | 碎片 | 适用场景 | 本项目是否使用 |
| --- | --- | --- | --- | --- |
| heap_1 | 不能 | 无 | 只创建不删除 | |
| heap_2 | 能 | 有 | — | |
| heap_3 | 能 | 依赖 libc | 需要 malloc 兼容 | |
| heap_4 | 能 | 合并相邻空闲块 | 通用首选 | |
| heap_5 | 能 | 同 heap_4 | 多块不连续内存 | |
