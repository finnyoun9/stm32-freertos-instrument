# firmware · 代码归档

> 这一层放**代码**，并且严格区分来源。记录仓库的价值在于「哪段是我写的」，混在一起就说不清了。

## 目录约定

```text
firmware/
├── course-reference/   # 课程配套源码（原样归档，不改）
├── my/                 # 我在课程基础上自己写的 / 改的
└── README.md
```

## 归档要求

| 项 | 要求 |
| --- | --- |
| Keil 工程 | 保留 `.uvprojx` 与必需源文件；**不提交** `Objects/` `Listings/` `DebugConfig/` 等编译产物 |
| CubeMX | 保留 `.ioc`，便于复现时钟与外设配置 |
| FreeRTOS 内核 | 保留实际使用的版本与 `FreeRTOSConfig.h`（配置是重点） |
| 自己写的东西 | 在文件头注释里写清作者与日期 |
| 大文件 | 百度网盘里的课程资料不要整包塞进来，只放实际用到的部分 |
