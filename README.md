# STM32 FreeRTOS 示波器 · 学习与开发记录

跟着 **铁头山羊《FreeRTOS 教程（基于 HAL 库，自带示波器项目）》** 从零做一块开发板，把 FreeRTOS 从内核移植一路用到应用层，最后落在示波器项目上的**完整过程记录**。

这个仓库的定位是**记录本**，不是代码发布仓库：

- 记录**过程**：开发板怎么来的、环境怎么搭、内核怎么移植、每章做了什么、踩了什么坑。
- 记录**掌握的东西**：每个 FreeRTOS 机制「我理解成什么 / 在哪个文件的哪一行用到了 / 拿什么证明它真的跑了」。
- 记录**证据**：照片、串口日志、示波器截图、代码片段、commit。

> 原则：**没验证过的不写"已完成"。** 空白格比编出来的结论值钱。

## 现在怎么用

1. 先看 [`docs/03-学习进度.md`](docs/03-学习进度.md) 把课程章节过一遍，凡是做完的打勾并补一句「我做了什么」。
2. 每学一个机制，在 [`docs/04-FreeRTOS-知识体系.md`](docs/04-FreeRTOS-知识体系.md) 对应条目里写「我的理解 + 项目落点 + 证据」。
3. 凡是写了「已验证」的结论，必须在 [`docs/07-证据清单.md`](docs/07-证据清单.md) 里有对应条目。
4. 踩坑随手记进 [`docs/06-问题与排障日志.md`](docs/06-问题与排障日志.md)，别等想起来再补。
