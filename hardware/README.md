# hardware · 硬件资料

> 记录开发板的硬件链路。板子是课程配套板还是自己画的，决定这一层放什么。

| 目录 | 放什么 | 状态 |
| --- | --- | --- |
| `schematic/` | 原理图（PDF / 源文件） | ☐ 课程板原理图因版权移入私有仓（见 `firmware/course-reference/README.md`） |
| `pcb/` | PCB 源文件与渲染图 | ☐ |
| `gerber/` | 打板生产资料 | ☐ |
| `bom/` | BOM 与选型说明 | ☐ |
| `datasheet/` | 关键器件 datasheet | ☐ |
| `images/` | 实物照片（空板 / 焊后 / 接线 / 整机） | ☐ |

## 说明

- 课程配套板：至少放原理图 + 实物照片 + 引脚对应表（见 `docs/01-开发板.md`）。
- 自己画的板：走完整链路（原理图 → PCB → Gerber → BOM → 打板 → 焊接 → 上电）。
- 接线以照片为准，照片里拍清丝印和插针位置。
